# S-23 — AI knowledge base

> Part: Studio · Phase: 7 · Stages: garden · Depends on: S-21, S-08 · Status: draft (placeholder, to be designed)

## Goal
A second, hidden knowledge base where the AI keeps its own notes about the project (decisions it made, patterns it uses, what the user accepted or rejected), so that later generations are more consistent without the user writing everything down (D-23).

## Scope
To be designed in a dedicated AI design session. Topics to cover then: what the AI writes and when; how notes are kept small and correct; whether users can view, edit or reset them; retrieval (embeddings) vs summaries; privacy in the platform; how this relates to the prompt library's evaluation.

## User stories
- **US-1** `[garden]` As a user, the AI remembers what I accepted and rejected in this project, so that it stops repeating ideas I discarded.
  - Acceptance: to be defined in the design session.

## Risks and open questions
- Hidden state that changes AI behaviour can surprise users; some visibility ("what the AI remembers") is probably needed.
