# WibeBlock

Build web applications with AI without handing everything to the AI. You lay out pages as a tree of blocks with flex and grid tools; inside each block you describe what it should look like, and the AI generates its content and styling. A global theme and prompt keep the app consistent. **Compact** exports a standalone project (React first) that you fully own.

WibeBlock is a personal pet project, built in the open and used to learn platform technologies along the way (.NET, gRPC, RabbitMQ, Kafka, Neo4j, Kubernetes, Terraform…).
